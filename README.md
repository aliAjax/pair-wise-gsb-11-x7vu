# 油气回收检测复测台

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand、Ant Design
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

由油站设备巡检清单扩展而来，面向加油站油气回收检测与复测闭环：

- **检测登记**：选区域、枪号，登记液阻、密闭性衰减与气液比；任一指标越限即进入待复测，须填写责任人和期限。
- **复测闭环**：未闭环单只能登记关联原单的复测，不能记正常、不计入正常数；复测仍越限保留新旧值并顺延期限，全部合限才关闭原单。
- **更正留痕**：更正须填原因，旧版数据与原因另存，随复测链时间线展示。
- **受阻项**：列出枪号、指标、原值、最新值、限值与判定规则；受阻枪号闭环前不能登记新初检。
- **统计一致**：数据持久化在浏览器 localStorage，重载后复测链统计保持一致。

## 目录结构（数据 / 规则 / 页面分拆）

```
src/
  data/        类型、站点配置与种子数据、localStorage 持久化
  rules/       三项指标限值规则、复测链构建与统计、受阻项归集
  components/  指标录入、状态徽章、复测链时间线、复测/更正表单、链卡片
  pages/       检测登记、复测台、受阻项三个页面
```
